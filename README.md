# Portfolio-website-valentina-maffei-coy
Professional portfolio showcasing marketing and digital analytics projects.

## Technologies Used
- HTML5, CSS3, JavaScript
- Figma (mockups)
- Canva (branding and visuals)
- GitHub Pages (deployment)

## Features
- Interactive portfolio of projects
- Responsive design for desktop and mobile
- Sections for skills, projects, and contact
- Smooth navigation and professional layout

## Installation / Usage
1. Clone the repository:
https://github.com/valentinamaffeisjcc/portfolio-website.git
2. Open `index.html` in a browser
3. Explore the portfolio sections and projects
